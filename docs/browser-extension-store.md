# 브라우저 확장 기능 스토어 제출 자료

## 기본 정보

- 이름: 스트림 패널 웹 업무 도우미
- 분류: 생산성
- 짧은 설명: 스트림 패널에서 경기 나이스 복무·출장과 경기 에듀파인 기안·품의 화면까지 안전하게 이동합니다.
- 홈페이지: https://github.com/deepsky616/stream-panel
- 개인정보 처리 안내: https://github.com/deepsky616/stream-panel/blob/main/PRIVACY.md

## 상세 설명

스트림 패널 웹 업무 도우미는 윈도우용 스트림 패널과 엣지 또는 크롬을 연결합니다. 사용자가 스트림 패널의 웹 업무 키를 누르면 경기 나이스의 복무·출장 화면이나 경기 에듀파인의 기안·품의 화면까지 정해진 메뉴만 찾아 이동합니다.

로그인, 인증서와 암호 입력은 사용자가 직접 수행합니다. 확장 기능은 문서 내용을 읽거나 외부로 전송하지 않으며 저장, 제출, 상신, 승인과 결재 단추를 자동으로 누르지 않습니다.

## 한 가지 목적

이 확장 기능의 유일한 목적은 윈도우용 스트림 패널이 요청한 네 가지 웹 업무 화면 이동을 엣지와 크롬에서 수행하는 것입니다. 광고, 분석, 검색 변경과 원격 스크립트를 포함하지 않습니다.

## 권한 설명

- `storage`: 스트림 패널이 생성한 임의 연결값을 브라우저 로컬 저장소에 보관합니다.
- `http://127.0.0.1:38473/*`: 같은 컴퓨터에서 실행 중인 스트림 패널과 연결 상태와 고정 명령을 주고받습니다.
- `https://goe.neis.go.kr/*`: 경기 나이스에서 사용자가 요청한 복무 또는 출장 메뉴를 찾습니다.
- `https://klef.goe.go.kr/*`: 경기 에듀파인에서 사용자가 요청한 기안 또는 품의 메뉴를 찾습니다.
- `all_frames`: 나이스와 에듀파인이 업무 화면을 내부 프레임으로 표시하는 경우에도 정해진 메뉴를 찾기 위해 필요합니다.

## 심사 시험 순서

1. 윈도우에 최신 Stream Panel을 설치하고 실행합니다.
2. Stream Panel 편집기에서 설정, 웹 업무 연결을 엽니다.
3. 심사할 브라우저에서 확장 기능을 설치합니다.
4. Stream Panel의 연결 시험을 누릅니다.
5. 확장 기능 팝업에 브라우저가 스트림 패널과 연결되었다는 문구가 표시되는지 확인합니다.

나이스와 에듀파인은 교육기관 인증 계정이 필요한 업무 시스템이므로 공개 시험 계정을 제공할 수 없습니다. 계정이 없는 심사자는 연결 시험과 권한 제한을 확인할 수 있으며, 실제 업무 화면 이동은 교육기관 계정으로 로그인한 환경에서만 동작합니다.

## 제출 뒤 기록할 주소

- 크롬 웹 스토어: 심사 통과 뒤 `src/shared/webWorkflows.ts`의 `BROWSER_EXTENSION_STORE_URLS.chrome`에 입력
- 엣지 추가 기능: 심사 통과 뒤 `src/shared/webWorkflows.ts`의 `BROWSER_EXTENSION_STORE_URLS.edge`에 입력

두 주소가 입력되면 설정 화면은 개발자 모드 안내를 숨기고 `확장 기능 설치` 버튼을 표시합니다. 기존 내부 통신 방식과 보안 제한은 바뀌지 않습니다.
