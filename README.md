# Stream Panel

Stream Panel은 윈도우 바탕화면에 항상 띄워 두고 쓰는 소프트웨어 실행 패널입니다. Elgato Stream Deck의 장치와 편집기 흐름을 소프트웨어만으로 재현합니다. 웹사이트, 폴더, 파일, 설치된 앱을 오른쪽 목록에서 키로 끌어다 놓고 패널에서 바로 실행할 수 있습니다.

## 설치

1. [릴리즈 페이지](https://github.com/deepsky616/stream-panel/releases)에서 `StreamPanel-x.y.z-Setup.exe`를 내려받습니다.
2. 설치 파일을 실행하고 설치할 폴더를 선택합니다.
3. 설치가 끝나면 Stream Panel이 자동으로 실행됩니다.

### 윈도우 보안 경고

처음 실행할 때 **"Windows에서 PC를 보호했습니다"** 화면이 나올 수 있습니다. `추가 정보`를 누른 뒤 `실행`을 선택하세요. 코드 서명 인증서를 구매하지 않은 공개 소스 앱이라 나타나는 정상적인 경고입니다. 설치 파일은 이 저장소의 깃허브 자동 작업이 공개된 소스에서 직접 만듭니다.

## 사용법

1. 패널의 톱니바퀴 버튼이나 트레이 메뉴에서 편집기를 엽니다.
2. 오른쪽 액션 목록에서 웹사이트, 폴더, 파일, 앱 또는 폴더 만들기를 왼쪽 빈 키로 끌어다 놓습니다.
3. 아래 속성 영역에서 이름, 아이콘, 색상과 실행 대상을 지정합니다. 변경 내용은 따로 저장 버튼을 누르지 않아도 바로 반영됩니다.
4. 폴더 키 위에 다른 키를 잠시 올려 폴더 안으로 넣고 관련 키를 묶습니다.
5. 작은 패널에서 키를 눌러 대상을 실행합니다.

탐색기에서 파일이나 폴더를 편집기 키로 바로 끌어다 놓을 수도 있습니다. 브라우저 주소를 놓으면 웹사이트 키가 만들어지고, 이미지 파일을 기존 키 위에 놓으면 아이콘이 바뀝니다.

## 단축키

| 키 | 동작 |
|---|---|
| `Ctrl+Alt+D` | 패널 표시 또는 숨김 |
| 화살표 | 키 사이 이동 |
| `Enter` 또는 `Space` | 키 실행, 선택 또는 폴더 진입 |
| `Backspace` | 상위 폴더로 이동 |
| `Ctrl+왼쪽` 또는 `Ctrl+오른쪽` | 이전 쪽 또는 다음 쪽 |
| `Ctrl+C` | 키 복사 |
| `Ctrl+X` | 키 잘라내기 |
| `Ctrl+V` | 빈 키에 붙여넣기 |
| `Delete` | 선택한 키 삭제 |
| `F2` | 편집기에서 이름 편집 |

전역 단축키는 설정에서 바꿀 수 있습니다. 다른 앱이 이미 쓰는 조합이면 이전 단축키로 자동으로 돌아갑니다.

## 트레이 메뉴

- 패널 표시 또는 숨기기
- 편집기 열기
- 설정 열기
- 업데이트 확인
- 완전히 종료하기

패널의 닫기 버튼은 앱을 종료하지 않고 패널만 숨깁니다. 앱을 완전히 끝내려면 트레이 메뉴의 `종료`를 사용하세요.

## 설정과 백업

설정 파일은 `%APPDATA%\stream-panel\config.json`에 저장됩니다. 사용자 아이콘과 캐시도 같은 폴더 아래에 있습니다.

백업하려면 Stream Panel을 종료한 뒤 `stream-panel` 폴더 전체를 다른 위치에 복사하세요. 알 수 없는 미래 버전의 설정이나 손상된 설정을 발견하면 앱이 같은 폴더에 `config.backup-시간값.json`을 만들고 기본값으로 복구합니다.

## 개발

Node 22 이상이 필요합니다.

```bash
npm install
npm run dev
```

검사와 빌드 명령은 다음과 같습니다.

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm run build:win
```

맥과 리눅스에서도 화면 개발은 할 수 있지만 설치된 앱 검색, 윈도우 바로가기 해석, 스토어 앱 실행은 윈도우에서만 지원합니다. 네트워크가 없어도 앱 실행과 편집은 동작하며 웹사이트 아이콘만 글자 표시로 바뀝니다.

## 공개와 업데이트

`v1.0.0` 같은 버전 태그를 밀면 깃허브 자동 작업이 윈도우 설치 파일, 블록맵과 `latest.yml`을 만들어 정식 릴리즈에 첨부합니다. 설치본은 새 버전을 내려받은 뒤 앱을 다시 시작할 때 적용합니다.
