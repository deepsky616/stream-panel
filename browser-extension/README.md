# 스트림 패널 웹 업무 도우미

엣지와 크롬에서 스트림 패널의 나이스·에듀파인 업무 키를 실행하는 확장 기능입니다.

## 개발 중 설치

1. 스트림 패널 설정의 `웹 업무 연결`에서 `확장 관리 열기`를 누릅니다.
2. 브라우저의 개발자 모드를 켭니다.
3. `압축 해제된 확장 기능을 불러오기`를 누릅니다.
4. 스트림 패널에서 연 `browser-extension` 폴더를 선택합니다.
5. 스트림 패널로 돌아가 `연결 시험`을 누릅니다.

로그인 정보와 인증서 정보는 읽거나 저장하지 않습니다. 저장·제출·결재 단추도 누르지 않습니다.
